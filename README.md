# Traveller's Word

**Play in your browser: <https://pelailes-cmd.github.io/travellers-word/>**

A portrait word-battle RPG. Spell words on a 4x4 board of letter tiles to fight your
way across five lands, or duel other travellers online.

This repository holds only the built game that GitHub Pages serves.
To delete an online account, see
<https://pelailes-cmd.github.io/travellers-word/delete-account.html>.
